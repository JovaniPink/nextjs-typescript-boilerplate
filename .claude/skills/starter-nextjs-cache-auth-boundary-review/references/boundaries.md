# Authorization and cache tracing

Inventory configured capabilities first. Authenticate and authorize at the server-side read/write owner; treat client checks as UX. Trace cache identity and lifetime for user-specific data and invalidation after mutation/logout. Cookie/header APIs and Cache Components behavior must match installed Next documentation. Do not scaffold missing authentication or enable caching as an audit side effect.

Authority: [Authorization and cache tracing](https://nextjs.org/docs/app/guides/authentication). Documentation informs correctness; it is not evidence that this workflow ran successfully in an installed client.
