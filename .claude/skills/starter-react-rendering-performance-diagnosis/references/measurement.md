# Measured rendering diagnosis

Capture a stable interaction and compare equal inputs/build mode/device. Inspect effects that derive state already available during rendering, identity churn and ownership breadth. Distinguish network waterfall, serialization, render and commit costs. Memoization has a cost and must address observed work. A code proposal is a hypothesis until matched before/after measurements show the result.

Authority: [Measured rendering diagnosis](https://react.dev/learn/you-might-not-need-an-effect). Documentation informs correctness; it is not evidence that this workflow ran successfully in an installed client.
